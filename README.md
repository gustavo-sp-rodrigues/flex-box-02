# Atividade - Flexbox 02

Este repositório contém a resolução da atividade **Flexbox 02**, desenvolvida para a disciplina de **Pesquisa e Inovação I** da São Paulo Tech School (SPTech).

## 📌 Sobre o Projeto
O objetivo desta atividade é praticar o uso do **CSS Box Layout (Flexbox)**, 
com foco no alinhamento de caixas utilizando a propriedade `justify-content`. O projeto aborda a criação de layouts 
responsivos, a estruturação de elementos na página e o alinhamento dos componentes HTML.
